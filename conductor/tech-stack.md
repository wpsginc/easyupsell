# Technology Stack

## Core Technologies
- **Language:** Python 3.11+
- **CLI Framework:** Typer
- **Data Analysis:** Pandas
- **Database:** BigQuery (Google Cloud)
- **API Clients:** `requests` (BigCommerce), `openai` (LLM)
- **Validation:** Pydantic
- **Matching:** RapidFuzz (Fuzzy Search)
- **Output:** CSV

## Infrastructure
- **Version Control:** Git
- **Dependency Management:** `pip` / `requirements.txt`
