## 1. Security Gaps (CRITICAL)

### GAP-SEC-001: NetSuite OAuth Signature Validation [P0]
**Category:** Security  
**Impact:** Authentication bypass, credential leakage  
**Location:** `src/netsuite/auth.py`

**Gap Description:**
NetSuite OAuth 1.0a implementation has no tests for:
- Signature generation correctness
- Timestamp replay attack prevention
- Nonce collision handling
- Percent-encoding edge cases (special characters, Unicode)
- HMAC-SHA256 signature verification against known test vectors

**Evidence:**
- `src/netsuite/auth.py:102-120` — `sign_request()` function untested
- `src/netsuite/auth.py:68-98` — `create_signature_base_string()` untested
- No test file `tests/test_netsuite_auth.py` exists
- OAuth 1.0a is security-critical; incorrect implementation = credential theft

**Attack Vectors:**
1. Malformed percent-encoding could leak secrets
2. Weak nonce generation (UUID collision over time)
3. Timestamp manipulation (replay attacks)
4. Signature mismatch errors silently failing

**SDD:** [tests/gap/SDDs/SDD-Security-NetSuiteOAuth.md](#sdd-sec-001)

---

### GAP-SEC-002: BigCommerce API Token Exposure [P1]
**Category:** Security  
**Impact:** Credential leakage in logs/errors  
**Location:** `src/bigcommerce/client.py`

**Gap Description:**
No tests verify that API tokens are NOT exposed in:
- Exception messages

**Evidence:**
- `src/bigcommerce/client.py:32-36` — Token set in session headers
