## 1. Identified Gaps

### G1: NetSuite Sync Batch Size Ignored
- **Severity:** P1 (High)
- **Component:** `src/sync/netsuite.py`
- **Description:** The `NetSuiteSyncJob.run()` method ignores the configured `batch_size`, potentially loading all pending records into memory.
- **SDD:** [SDD-Sync-BatchProcessing.md](../../gap/SDDs/SDD-Sync-BatchProcessing.md)

### G2: API Input Validation Missing
- **Severity:** P2 (Medium)
- **Component:** `src/api.py`
- **Description:** API endpoints accept unbounded inputs, risking DoS.
- **SDD:** [SDD-API-InputValidation.md](../../gap/SDDs/SDD-API-InputValidation.md)

### G3: CSV Injection Mitigation (Sanitization)
- **Severity:** P1 (Critical)
- **Component:** `scripts/migrate_csv_to_db.py`
- **Description:** The migration script imports malicious formulas (e.g., `=cmd|...`) without sanitization, creating a Stored CSV Injection vulnerability if data is exported.
- **SDD:** [SDD-Security-CSV-Sanitization.md](../../gap/SDDs/SDD-Security-CSV-Sanitization.md)
- **Assigned To:** `rem_security`

### G4: Database Path Restriction
- **Severity:** P1 (High)
- **Component:** `scripts/migrate_csv_to_db.py`
- **Description:** The migration script allows arbitrary DB paths (`--db`), enabling arbitrary file writes or database creation in unauthorized locations.
- **SDD:** [SDD-Security-Path-Restriction.md](../../gap/SDDs/SDD-Security-Path-Restriction.md)
- **Assigned To:** `rem_security`

### G5: Bulk Migration Performance
- **Severity:** P2 (Medium)
- **Component:** `src/db.py` / `scripts/migrate_csv_to_db.py`
- **Description:** The migration script commits per-row, causing O(N) fsyncs and poor performance on large datasets.
- **SDD:** [SDD-Performance-Bulk-Migration.md](../../gap/SDDs/SDD-Performance-Bulk-Migration.md)
- **Assigned To:** `rem_performance`

### G6: Malformed CSV Robustness
- **Severity:** P2 (Medium)
- **Component:** `scripts/migrate_csv_to_db.py`
- **Description:** `csv.DictReader` usage lacks handling for malformed lines, potentially crashing the entire migration.
- **SDD:** [SDD-Robustness-Malformed-CSV.md](../../gap/SDDs/SDD-Robustness-Malformed-CSV.md)
- **Assigned To:** `rem_bedilia`

### G7: End-to-End Integration
- **Severity:** P3 (Low)
- **Component:** Integration
- **Description:** No automated test verifies the full `Analyze -> Export -> Migrate -> Serve` cycle.
- **SDD:** [SDD-Integration-E2E-Migration.md](../../gap/SDDs/SDD-Integration-E2E-Migration.md)
- **Assigned To:** `rem_uat`
