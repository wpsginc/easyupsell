### 🔴 P1: CSV Formula Injection (BUG_CHAOS_001)
**Test:** CSV export with malicious formula payloads  
**Result:** NO SANITIZATION - Formulas written directly to CSV  
**Impact:** HIGH - CSV files opened in Excel/Google Sheets execute formulas  
**Location:** `easyupsell/commands/export.py:44-68`, `easyupsell/core/output.py:27-66`

**Vulnerable Payloads:**
```csv
source_category,recommended_sku
=1+1,TEST1
@SUM(A1:A10),TEST2
+cmd|/c calc,TEST3
-2+3+cmd|/c calc,TEST4
```

**Attack Vector:**
1. Malicious product data from BigCommerce API
2. Exported to CSV via `easyupsell export peasisoft`
3. User opens in Excel → Formula executes (potential RCE)

**Recommendation:**
```python
def sanitize_csv_value(value: str) -> str:
    """Prevent CSV injection by escaping formula chars."""
    if value and value[0] in ('=', '+', '-', '@'):
        return "'" + value  # Prefix with single quote
    return value
```

**Files to Fix:**
- `easyupsell/commands/export.py` - lines 54-61
- `easyupsell/core/output.py` - lines 33-34, 66-67

### 🔴 P1: Deep JSON Nesting DoS (BUG_CHAOS_002)
**Test:** Malicious JSON with deep nesting  
**Result:** RecursionError crashes Python interpreter  
**Impact:** HIGH - Corrupted brands.json can crash all brand commands  
**Location:** `easyupsell/commands/brands.py:32`

**Attack Payload:**
```python
'[' * 10000 + ']' * 10000  # Deeply nested array
```

**Attack Vector:**
1. Manual edit of `data/priority_brands.json`
2. File system corruption
3. Malicious contribution/PR

**Recommendation:**
```python
def load_brands() -> list[str]:
    """Load brands from config file with size limits."""
    if BRANDS_FILE.exists():
        # Check file size first
        if BRANDS_FILE.stat().st_size > 1024 * 100:  # 100KB limit
            console.print("[red]Error:[/red] Brands file too large")
            return DEFAULT_BRANDS.copy()
        
        try:
            content = BRANDS_FILE.read_text()
            # Limit recursion depth
            import sys
            old_limit = sys.getrecursionlimit()
            sys.setrecursionlimit(100)
            try:
                data = json.loads(content)
            finally:
                sys.setrecursionlimit(old_limit)
            
            if not isinstance(data, list):
                raise ValueError("Invalid brands format")
            return data
        except (json.JSONDecodeError, RecursionError, ValueError) as e:
            console.print(f"[yellow]Warning:[/yellow] Corrupted brands file: {e}")
            console.print("Using default brands")
            return DEFAULT_BRANDS.copy()
    return DEFAULT_BRANDS.copy()
```

## Additional Observations

### Code Quality Issues
1. **No subprocess validation** - `analyze.py:45` uses `subprocess.Popen` without shell=False explicitly set (though Python defaults to False)
2. **sys.path manipulation** - Multiple files use `sys.path.insert(0, ...)` which can cause import issues
3. **Hardcoded paths** - Relative paths like `Path("data/...")` assume CWD is repo root

### Security Best Practices Missing
1. **Input validation** - No schema validation for CSV imports
2. **File size limits** - No limits on uploaded/processed files
3. **Rate limiting** - No protection against API abuse (if exposed as service)
4. **Audit logging** - No logging of file modifications
